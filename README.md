## Latest update — September 8, 2026

The [Server Content Editors update](https://github.com/Mateuzkl/NexaMap-Editor/pull/34) is merged into the official `main` branch. NexaMap can now discover, inspect, create, and safely edit server content from the active WorkspaceSession.

### Native editors

- **Monster Editor:** Main, Look, Attacks, Defenses, Resistances, Loot, Summons, Voices, and Source.
- **NPC Editor:** Main, Look, Messages, Shop, Travel, Behavior, and Source.
- **Spell Editor:** registration and implementation metadata, vocations, effects, projectiles, and areas.
- Searchable and virtualized content browsers show names, formats, and relative source paths.
- Real item, outfit, effect, projectile, and spell-area previews use the active client resources.
- New Monster and NPC definitions are generated by the provider detected for the active server family.

### Source safety

- Recognized XML/Lua spans are patched without regenerating arbitrary source files.
- Unknown fields, comments, callbacks, custom functions, and dynamic Lua remain preserved.
- Save validates the source and keeps the editor open.
- Debounced autosave reports dirty, saved, error, and conflict states.
- External changes pause autosave and can be inspected side by side.
- Fingerprints and transactional writes prevent silent overwrites.
- Successful saves refresh only the affected content paths.

### Reusable spell areas

The visual area creator is shared by the global Spell Editor and Monster attack workflow. It discovers real server libraries such as `data/scripts/lib/spell_lib.lua`, traditional spell libraries, and Crystal/Canary registration libraries.

Users can draw affected tiles, choose exactly one center, select a destination library, and save a validated `AREA_*` constant. Existing functions and definitions remain unchanged.

### Supported layouts

| Server family | Support |
| --- | --- |
| Modern TFS Lua / revscriptsys, including TFS 1.8 8.60 | Complete |
| Traditional TFS XML + Lua, including Dragon Souls | Complete |
| Crystal / Canary Lua datapacks | Complete |
| Structural custom TFS with ServerID/ClientID pairs, `appearances.dat`, and `items.xml` | Supported |

The diagnostic console is now optional and disabled by default. It can be enabled in Preferences while `nexamap.log` remains independently available.

## Changelog

### September 8, 2026 — Server Content Editors ([PR #34](https://github.com/Mateuzkl/NexaMap-Editor/pull/34))

- Added the native Monster, NPC, and global Spell editing stack.
- Added provider-aware XML/Lua creation and source-preserving updates.
- Added real asset previews, colored outfit controls, loot item previews, and spell visualization.
- Added the reusable visual spell-area creator.
- Added debounced autosave, external-file monitoring, and comparison/conflict handling.
- Added lazy per-workspace indexing, immutable snapshot reuse, targeted refreshes, and metadata caches.
- Added structural custom-TFS item-resource detection and remapping.
- Fixed the spell-area DPI construction crash, encoding issues, registry path normalization, and unity/CI formatting failures.

### September 6, 2026 — Map maintenance tools ([PR #33](https://github.com/Mateuzkl/NexaMap-Editor/pull/33))

- Added a Corpse Decay Report with grouped IDs, decay risk, export, and navigable map results.
- Added whole-map Action ID / Unique ID cleanup, including items inside containers.
- Added Item IDs to map item search labels.

### September 6, 2026 — Independent sessions restored ([PR #32](https://github.com/Mateuzkl/NexaMap-Editor/pull/32))

- Fixed the regression that closed World A when World B used another client/server.
- Preserved each tab's Editor, EditorResourceSession, workspace, items, materials, brushes, creatures, graphics, and copy buffer.
- Improved Cross-Client Paste matching, compatible auto-mapping, thumbnails, and destination scanning.
- Added regression coverage for switching, copying, pasting, and closing maps in both directions.

### September 5, 2026 — NexaMap 5.0 ([PR #31](https://github.com/Mateuzkl/NexaMap-Editor/pull/31))

- Added persistent Client + Server Workspaces with automatic resource discovery.
- Added independent map sessions and Cross-Client Copy & Paste.
- Added the Quick Command Palette, Favorites 2.0, dockable minimap, and Map Diagnostics.
- Added improved tooltips, visual container previews, navigation, and session-aware palettes.
- Expanded local Playtest with movement, interaction, HUD, lighting, weather, and camera handling.
- Added authenticated real-time multiplayer with snapshots, revisions, transactions, permissions, locks, chat, cursors, pings, reconnection, and resynchronization.
- Added 4×4 chunk revisions, CPU geometry caching, persistent GPU ground caching, atlas tracking, and FBO integration.
- Hardened ownership, callbacks, editor disposal, OpenGL teardown, diagnostic cancellation, and unity builds.
